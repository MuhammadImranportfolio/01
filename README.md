# Muhammad Imran — Biotechnology Research Portfolio

This is a GitHub-ready static website based on the portfolio content supplied in the project and a visual color direction inspired by the public BioEcoTech Research Cluster website.

## Files
- `index.html` — complete website structure/content
- `style.css` — responsive styling and BioEcoTech-inspired green palette
- `images/profile.jpg` — add your own profile image here
- `cv.pdf` — optionally add your CV here

## BioEcoTech-inspired palette
- Deep forest: `#0B3D2E`
- Primary green: `#177B52`
- Teal accent: `#1F9D7A`
- Soft mint: `#EAF6F0`
- Warm off-white: `#F7F8F5`
- Charcoal: `#18221E`

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `style.css`.
3. Create an `images` folder and upload `profile.jpg`.
4. Optionally upload `cv.pdf`.
5. Go to **Settings → Pages**.
6. Select **Deploy from a branch**, choose `main`, folder `/root`, and save.
